## Catatan Workflow

- Landing page harus memakai asset dari `public/assets/`.
- Asset berstatus `ready` boleh dipakai untuk MVP.
- Asset `placeholder-ready` aman dirender, tetapi tetap perlu diganti final saat polish.
- Asset `needs-production` perlu export final/optimasi sebelum production.
- Jika mengganti asset final, pertahankan path dan nama file agar Blade tidak perlu diubah.
